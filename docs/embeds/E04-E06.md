# E04–E06 implementation evidence

Completed 2026-10-05. No article source was migrated, no deployment was performed, and existing unrelated edits in both repositories were preserved. The article renderer and assets are implemented, while article-wide theme/print styling and pilot migration remain E07/E08.

## E04: complete saved figures

`src/embeds/exportFigure.tsx` renders the frozen contract data into four independent variants: 360px and 680px surfaces in light and dark themes. It mounts the shared plot offscreen with surface-scoped tokens, waits for fonts/layout, then serializes a self-contained SVG through `src/utils/exportChart.ts`. Export colors come from the render surface, legend wrapping uses measured SVG text, and clipping IDs are made unique. The dashboard theme, selection, URL, and storage are not changed. `TelemetryPlot` accepts a larger export axis size while keeping its dashboard default.

`src/embeds/__tests__/exportFigure.test.tsx` parses all four XML documents and checks geometry, minimum text size, theme colors, local references, unique IDs, and absence of external URLs or CSS variables. A real browser export of the pedal fixture produced 360×246 and 680×258 SVG variants, each about 26–27 KB. The speed fixture was also run through the article validator. These sizes are far below E12's 150 KiB-per-image target.

## E05: publication composer

The dashboard Embed actions open `src/embeds/EmbedComposer.tsx` for either the current supported panel or a deliberate selection when the current tab has no supported figure. The dialog captures the chart data and scope once, shows exact session/lap/driver context, a required title/accessibility description/caption, completeness status, the analysis link, and narrow/wide previews. It downloads a validated `.f1embed.json`, copies the `TELEMETRY:` marker when clipboard access is available, and exposes a selectable manual fallback. Legacy iframe creation remains available only through its labelled choice. Offscreen rendering is lazy-loaded, aborts on panel change/close, and errors leave the draft in place.

`VisualWorkflow.test.tsx` covers the composer defaults, explicit legacy path, supported panel selection and stable scope. Export tests cover the frozen render surface. Full telemetry CI passed, including lint, standalone production build, token check and 169 tests. The canonical `npm run build:f1stories` assembly also passed and emitted a separate lazy `exportFigure` chunk (1.41 KiB gzip); the chart runtime is not part of the initial page chunk.

## E06: article publication path

The article checkout at `../f1StoriesPage` now has a dedicated `blog-module/build/telemetry-figure.js` validator/renderer. TXT and DOCX marker paths resolve only source-local bundle files, including the optional local `embeds/` directory. The host independently validates the contract, bounds, scope/data relationship and each SVG's XML tree, dimensions, allowed elements/attributes, fragment references and local IDs. It rejects DTD/entities, scripts, event attributes, `foreignObject`, external URLs and unsafe marker paths. Output is escaped editorial HTML plus responsive local image references and a validated analysis link; generic raw-widget restrictions are unchanged.

The telemetry contract fixture was copied byte-for-byte into the article test fixtures. Six targeted tests pass, covering same-output TXT and DOCX processing, deterministic names, beside-source and `embeds/` resolution, malformed/missing/hostile input and separation from generic widgets. An actual browser-export bundle also passed both the telemetry contract validator and host renderer. The public-artifact script was exercised with a temporary article entry and included all four deterministic SVG variants in the assembled `dist`; the pre-existing ignored `dist` was restored afterward. The media policy documents generated telemetry vectors as a bounded exception. No build network access is needed.

Article commands run:

```sh
node --test blog-module/build/__tests__/telemetry-figure.test.js blog-module/build/__tests__/embed-hardening-guard.js
```

Both pass. The broader `npm run test:blog` was also attempted but currently fails in pre-existing unrelated dirty BetCast work in the article checkout: `article-frame-bridge.test.js` times out and then reports an uncaught frame error, while `betcast.test.js` has a JavaScript syntax error at line 129. Those files were left untouched. The focused E06 suite and embed-hardening guard pass independently.
